# Руководство пользователя

Руководство описывает два сценария: работу студента и работу преподавателя.
Оба сценария выполняются в веб-клиенте; прямые запросы к API через `curl` нужны
только при отладке.

## Сценарий студента: сдать работу

1. Открыть веб-клиент и войти по номеру зачётной книжки.
2. В списке **Мои работы** найти нужную лабораторную работу. Список показывает код,
   название и срок сдачи.
3. Нажать **Сдать**. Клиент отправляет `POST /api/v1/submissions`.
4. Убедиться, что статус работы сменился на «На проверке». Это состояние
   `submitted`.
5. После проверки статус станет «Оценено» (`graded`) или «На доработку»
   (`returned`).

Если работа уже была сдана, клиент покажет сообщение «Сдача по этой работе уже
существует» — сервер вернул `409`.

## Сценарий преподавателя: выставить оценку

1. Открыть раздел **Очередь проверки** — в нём только записи со статусом
   `submitted`.
2. Выбрать работу из списка. Карточка показывает студента, работу и дату сдачи.
3. Выставить оценку от 2 до 5 и при необходимости добавить комментарий.
4. Нажать **Сохранить**. Клиент отправляет `PATCH
   /api/v1/submissions/{submissionId}`; статус меняется на `graded`.
5. Чтобы вернуть работу на доработку, выбрать **Вернуть** — статус станет
   `returned`, оценка не сохраняется.

## Сценарий преподавателя: выгрузка сводки

1. Открыть раздел **Отчёты**.
2. Указать группу и период.
3. Нажать **Скачать CSV**. Отчётный модуль формирует файл с колонками
   `student`, `work`, `submitted_at`, `grade`.

## Типичные ошибки

| Сообщение в интерфейсе | Причина | Что делать |
| --- | --- | --- |
| «Студент не найден» | Неверный номер зачётной книжки | Проверить номер, обратиться к куратору |
| «Сдача по этой работе уже существует» | Работа сдана ранее | Открыть карточку работы и посмотреть статус |
| «Оценка должна быть от 2 до 5» | Введено значение вне диапазона | Исправить значение |
| «Сервис недоступен» | Нет связи с API | Повторить попытку через несколько минут |
