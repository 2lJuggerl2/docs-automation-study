# Общие сведения

**УЛР** (учебный лабораторный реестр) — внутренний REST-сервис техникума, который
хранит сведения о лабораторных работах и результатах их выполнения. Сервис заменил
таблицу, которую вёл преподаватель вручную: теперь работы, студенты и сдачи живут в
одной базе, а оценки выставляются по журналу, а не по переписке.

## Назначение

Сервис решает три задачи:

1. **Каталог работ.** Единый список лабораторных работ с привязкой к дисциплине,
   номеру и сроку сдачи.
2. **Учёт сдач.** Фиксация факта выполнения работы студентом, даты сдачи и оценки.
3. **Отчётность.** Выгрузка сводки по группе за период в CSV.

## Границы системы

| Входит в систему | Не входит |
| --- | --- |
| Каталог работ и дисциплин | Электронный журнал успеваемости |
| Учёт студентов и учебных групп | Расчёт стипендии |
| Фиксация сдач и оценок | Хранение файлов самих работ |
| Выгрузка сводок в CSV | Аутентификация через внешний SSO |

## Термины

- **Работа** — лабораторная работа с уникальным номером внутри дисциплины.
- **Студент** — обучающийся, закреплённый за одной учебной группой.
- **Сдача** — запись о том, что студент предъявил работу; содержит дату и оценку.
