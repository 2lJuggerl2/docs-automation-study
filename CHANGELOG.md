# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версия соответствует полю `version` в `package.json`.

## [1.0.0] — 2026-02-20

### Добавлено

- Каталог лабораторных работ, учёт студентов и фиксация сдач.
- Спецификация REST API в `openapi/openapi.yaml` (OpenAPI 3.1).
- Схемы PlantUML: компоненты, последовательность сдачи, конвейер публикации.
- Сайт документации на GitHub Pages, собираемый из Markdown.
- Линтер документации `tools/check.mjs` в конвейере GitHub Actions.
